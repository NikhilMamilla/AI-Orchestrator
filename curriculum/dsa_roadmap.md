# DSA Ultra PRO MAX Roadmap 🚀

This roadmap defines the core syllabus the AI Learning Orchestrator will master. Our agents are designed to be expert tutors in these 22+ domains.

## 🟢 1. Foundations (The Baseline)
- **Time & Space Complexity**: Big-O, Big-Ω, Big-Θ analysis.
- **Recursion basics**: Call stack, termination conditions.
- **Iteration vs Recursion**: Space-time trade-offs.
- **Bitwise basics**: Binary representation and operations.

## 🟢 2. Arrays (Building Blocks)
- **Basics**: Traversal, Insertion/Deletion, Search (Linear/Binary).
- **Techniques**: Prefix Sum, Sliding Window, Two Pointers.
- **Classic Algos**: Kadane’s (Max Subarray), Dutch National Flag (3-way partition).
- **Advanced**: Merge Intervals, Matrix Manipulation (2D Arrays), Subarray problems.

## 🟢 3. Strings (Pattern Matching)
- **Manipulation**: Palindromes, Anagrams, Frequency Counting.
- **Searching**: Rabin–Karp, KMP (Knuth-Morris-Pratt), Z Algorithm.
- **Structures**: String Hashing, Tries (see Tries section).
- **Analysis**: Substrings vs Subsequences.

## 🟢 4. Bit Manipulation (Low-Level Magic)
- **Operations**: AND, OR, XOR, NOT, Shifts.
- **Tricks**: Check power of 2, Set/Clear/Toggle specific bits, Bit masks.
- **Advanced**: Subset generation using bits, XOR properties.

## 🟢 5. Mathematics for DSA
- **Number Theory**: GCD/LCM (Euclid), Primes (Sieve of Eratosthenes).
- **Modular Algos**: Fast exponentiation, Modular inverse.
- **Counting**: Combinatorics, Pigeonhole principle.

## 🟢 6. Recursion & Backtracking
- **Patterns**: Subsets, Permutations, Combination Sum.
- **Classic Games**: N-Queens, Sudoku Solver, Rat in Maze.
- **Optimization**: Pruning, state-space reduction.

## 🟢 7. Linked List
- **Types**: Singly, Doubly, Circular.
- **Pointers**: Reversing, Cycle Detection (Floyd’s Cycle Finding), Middle element.
- **Manipulation**: Intersection points, Merging sorted lists, Nth node removal.

## 🟢 8. Stack
- **Implementation**: Array/LL based.
- **Monotonic Stack**: Next greater/smaller element, Largest rectangle in Histogram.
- **Expressions**: Infix/Prefix/Postfix conversions and evaluation.

## 🟢 9. Queue & Deque
- **Basics**: Simple, Circular, Deque.
- **Advanced**: Priority Queue (Heaps), Monotonic Queue.

## 🟢 10. Hashing
- **Internals**: HashMap/HashSet, Collision handling (Chaining/Probing).
- **Applications**: Frequency mapping, Two-sum/Three-sum patterns.

## 🟢 11. Sorting Algos
- **Simple**: Bubble, Selection, Insertion.
- **Complex**: Merge Sort, Quick Sort, Heap Sort.
- **Linear**: Counting, Radix, Bucket Sort.

## 🟢 12. Binary Search (Deep Dive)
- **Techniques**: Search on Answer, Lower/Upper Bound.
- **Variants**: Peak element, Rotated arrays, BS on 2D matrices.

## 🟢 13. Trees (Non-linear Core)
- **Theory**: Terminology, DFS (In/Pre/Post), BFS (Level Order).
- **Properties**: Height, Depth, Diameter, LCA (Lowest Common Ancestor).
- **Advanced**: Balanced Trees (AVL, Red-Black basics - *Added*).

## 🟢 14. Binary Search Tree (BST)
- **Operations**: Insertion, Deletion, Validation.
- **Search**: Kth smallest, Inorder successor/predecessor.

## 🟢 15. Heaps
- **Mechanics**: Min/Max Heap, Heapify, Priority Queue.
- **Patterns**: Top K problems, Merge K sorted arrays/lists.

## 🟢 16. Greedy Algos
- **Classic**: Activity selection, Fractional Knapsack, Huffman coding.
- **Schedules**: Job sequencing, Interval scheduling.

## 🟢 17. Graph Algos (System Core)
- **Traversal**: BFS, DFS.
- **Cycle**: Detection in Directed/Undirected graphs.
- **Paths**: Dijkstra, Bellman-Ford, Floyd Warshall.
- **Trees**: MST (Kruskal, Prim).
- **Connectivity**: Union Find (Disjoint Set), Bipartite Check.
- **Advanced**: SCC (Kosaraju/Tarjan), Bridges & Articulation Points (*Added*).

## 🟢 18. Dynamic Programming (The Master Topic)
- **Basics**: Memoization (Top-down) vs Tabulation (Bottom-up).
- **Classic**: 0/1 & Unbounded Knapsack, LCS, LIS.
- **Advanced**: Matrix Chain Multiplication, DP on Grids, DP on Trees, DP on Subsequences.
- **Optimization**: Bitmask DP.

## 🟢 19. Tries
- **Operations**: Insert, Search, Prefix match.
- **Advanced**: XOR max pair, Word dictionary.

## 🟢 20. Segment Trees & Fenwick Tree
- **Operations**: Point/Range queries, Lazy propagation.

## 🟢 21. Advanced Topics
- **Techniques**: Square Root Decomposition, Mo’s Algorithm, Meet in the middle.

## 🟢 22. Interview Patterns (Cheat Sheet)
- **Patterns**: Fast & Slow pointer, Merge intervals, Top K, Cyclic sort, BS on Answer.
