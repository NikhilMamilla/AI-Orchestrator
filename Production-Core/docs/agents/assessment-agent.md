# Assessment Agent (The Dynamic Evaluator)

The **Assessment Agent** is responsible for measuring student understanding and providing critical feedback loops for the adaptive pedagogy pipeline.

## 📋 Responsibilities
- **Diverse Generation**: Creates MCQs, coding challenges, and conceptual questions.
- **Deep Evaluation**: Analyzes student answers for partial credit and misconceptions.
- **Code Sandboxing**: Validates programming solutions using the **Judge0 API**.
- **Performance Analysis**: Provides recommendations (Advance, Practice, Review).

## 🛠️ Architecture
- `generator.py`: LLM-powered question construction.
- `evaluator.py`: Analysis engine for grading and feedback.
- `agent.py`: Orchestrator for assessments.
- `service.py`: Message Queue wrapper for async operations.

## 📡 API Endpoints
- `POST /api/v1/agents/assessment/generate`: Build a quiz from concept data.
- `POST /api/v1/agents/assessment/evaluate`: Grade student submissions.

## ⚡ Integration
- **MQ Channel**: `assessment.requests`
- **Output Channel**: `orchestrator.responses`
- **Dependencies**: `LLMService` (Groq), `CodeExecutionService` (Judge0).
